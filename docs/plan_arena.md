# ПЛАН: Единый интерактивный интерфейс двух моделей (Hermes ↔ OMP)

## Цель
Создать ОДИН красивый интерактивный терминальный интерфейс, где две модели (Hermes и OMP) общаются между собой автоматически, в ЕДИНОМ потоке сообщений. НЕ split-экраны — один общий чат-лог.

## Требования (жёсткие)
1. Единый интерфейс: один лог чата, ходы идут последовательно — [Hermes]: ... → [OMP]: ... → [Hermes]: ... (как обычный чат, без левых/правых панелей).
2. Автодиалог: модели общаются сами по заданной теме; лимит ходов (по умолчанию 10) и таймаут ожидания ответа (120 сек) — защита от зависания.
3. Красота: стиль Hermes (рамки ╭─ ╮, цвета, статус-бар: текущая модель, ход #N, время). Сообщения: [Hermes] — голубым, [OMP] — пурпурным, разделители между ходами.
4. Рабочие модели: обе реально отвечают (без заглушек).
5. Качество: перед сдачей — тест обеих моделей + судья-ревьюер с оценкой (минимум 8/10).

## Архитектура
- Python + urwid 4.0.8 (уже установлен): ListBox-лог (единый) + поле ввода темы + команды.
- Бэкенды моделей (программные вызовы, НЕ их TUI):
  - Hermes: hermes chat -q "<текст>" (неинтерактивный; ответ — из вывода/сессии)
  - OMP: echo "<текст>" | omp (stdin-режим, ждёт EOF) или omp "<текст>"
- Цикл автодиалога: тема → Hermes → ответ → OMP → ответ → Hermes → ... до лимита.
- Контекст: каждая модель получает историю диалога (последние 6 сообщений), чтобы не терять нить.

## Шаги реализации
1. Прототип: скрипт arena_chat.py — единый лог + вызовы обеих моделей через CLI; проверить, что ОБЕ отвечают.
2. Автодиалог: цикл с лимитом ходов, паузой 2-3 сек между ходами, защитой от зацикливания (не передавать один и тот же ответ дважды).
3. Оформление: рамки, цвета, статус-бар, разметка [Hermes]/[OMP], разделители, скролл лога.
4. Команды: /start <тема> · /stop · /turns N · /clear · /quit · /status.
5. Тесты (обязательно): 1) обе модели отвечают на тестовый вопрос; 2) автодиалог ≥4 ходов без сбоев; 3) интерфейс не падает; 4) ревьюер-субагент оценивает результат (≥8/10).
6. После сдачи — доработки постепенно силами обеих моделей.

## Критерии готовности
- Один интерфейс, ходы обеих моделей в едином логе.
- Автодиалог ≥4 ходов без сбоев.
- Оценка ревьюера ≥8/10.
- Скрипт: ~/.hermes/arena_chat.py, запуск: python3 ~/.hermes/arena_chat.py.
- Отчёт: что сделано, результаты тестов, оценка ревьюера, как запускать.
