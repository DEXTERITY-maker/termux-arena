# ☁ Nimbus AI — v0.0.1-alpha

Веб-чат с моделями **DeepSeek**. Без внешних зависимостей — только Python 3.8+
(стандартная библиотека). Работает в Termux, Linux, macOS.

## Быстрый старт

```bash
# 1. ключ (файл в .gitignore, в репозиторий не попадёт)
echo "DEEPSEEK_API_KEY=sk-..." > .env

# 2. запуск
bash nimbus/run.sh 8080        # или: python3 nimbus/server.py 8080

# 3. открыть http://localhost:8080
```

Termux: `pkg install python` — больше ничего не нужно.

## Возможности

- **Выбор модели** — список тянется из `GET /models` DeepSeek; если API недоступен,
  используется встроенный (`deepseek-chat`, `deepseek-reasoner`).
- **Потоковый ответ** (SSE) с кнопкой «стоп».
- **Блок «Рассуждения»** для reasoner-моделей (`reasoning_content`), сворачивается
  по завершении ответа.
- История чатов в localStorage, системный промпт, температура.
- Адаптивный тёмный интерфейс: боковая панель, на телефоне — выдвижное меню.
- Мини-Markdown: код-блоки, inline-код, **жирный**, *курсив*, заголовки.

## Безопасность

- Ключ API **никогда не попадает в браузер** — запросы идут через локальный сервер.
- Весь вывод модели экранируется перед вставкой в DOM (XSS невозможен), сообщения
  пользователя вставляются через `textContent`.
- Раздача статики защищена от path traversal.
- Ключ в логах маскируется (`sk-8dd…0631`).

## API сервера

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/health` | `{ok, version, hasKey, baseUrl}` |
| GET | `/api/models` | `{models[], live, hasKey, version}` |
| POST | `/api/chat` | `text/event-stream`, кадры `{content|reasoning|warning|error}`, финал `[DONE]` |

## Переменные окружения

| Имя | По умолчанию | Описание |
|---|---|---|
| `DEEPSEEK_API_KEY` | — | обязателен для чата |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | можно указать совместимый endpoint |
| `PORT` | `8080` | аргумент командной строки имеет приоритет |
| `HOST` | `0.0.0.0` | |

## Тесты

```bash
bash nimbus/tests/run.sh      # 36 Python + 36 JS тестов
bash nimbus/tests/smoke.sh    # E2E: сервер + mock DeepSeek через curl
```

Тесты работают против локального mock-сервера, повторяющего формат ответов DeepSeek,
поэтому проходят без интернета и без расхода токенов.

## Известные ограничения v0.0.1-alpha

- Нет загрузки файлов и изображений.
- Нет подсчёта токенов и стоимости.
- История хранится только в браузере (localStorage), без синхронизации.
- Сервер однопользовательский, без авторизации — не выставляйте его в интернет как есть.
